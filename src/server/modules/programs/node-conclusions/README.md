# 节点结论原生存储续作（BOW-902）

本目录在已交付的领域与事务用例基础上实现真实 PostgreSQL 存储。`store.ts` 是私有存储适配器，不能直接暴露给客户端；调用方必须在当前授权用例的同一事务内使用。完整生产确认服务仍待846评分账本 selector、完整来源读取和锁协议，不提供默认 ready 或空授权替身。

## 已实现

- 稳定结论身份以节点/人员唯一；第一版和后续版本共用同一 advisory identity lock，以 expectedVersion 做 CAS。每版只 INSERT，旧原文、署名、评分依据和来源引用不覆盖。
- 按当前或指定版本读取；操作账本以账号/operationId 唯一，指向实际不可变版本，不重复保存一份可能漂移的回执 JSON。新适配器实例仍能读到旧操作对应的精确版本。
- `stored-version.ts` 核五列原生行，四个身份字段和 payload 的原始值、领域解析结果严格一致，深冻结返回副本。损坏数据统一为安全 conflict，不泄漏原始行或校验详情。
- append、审计和操作账本由同一调用事务提交。重复操作、版本竞争、实际外键错误和末尾异常回滚整笔写入。
- 当前权限、来源完整性和签署人绑定由领域用例再次核对。换绑后不能把旧签署人的成功操作当作本人的确认；有权限者仍可读历史并创建自己的新操作。该修复已前移至原 PR #275，续作普通合入，不隐藏旧片缺陷。

## 已验证和未验证

五文件统一运行137项：115项领域/用例/存储解码单测，9项原生上下文PG测试，13项真实存储PG测试。存储测试用化名签署行验证存储与事务，**不是**实际846人工评分确认快照的生产验收。旧context的授权测试也不能代替完整native确认流程中的并发撤权、换绑或确认版本CAS联验。

本轮使用X1在固定输入86b2ca2f67b67284b0a8602eb39a194abb3244fe上生成的受控临时迁移。运行前核对manifest中每个文件摘要；临时编号不是正式迁移编号，不提交这些SQL或metadata。测试默认使用正式`src/server/db/migrations`；仅显式受控验证时用`BOW902_TEST_MIGRATIONS`指定X1输入。正式迁移缺失时默认测试必须失败，不skip或临时手写DDL补表。

测试只从所有者指定的test-db.env注入TEST_DATABASE_URL，随机创建本机专属`_test`库，结束关闭连接并删除该库。完整集成测试先取得共享heavy槽，`--maxWorkers=2`，结束按令牌释放。没有供应商、生产库或真实人员数据。
